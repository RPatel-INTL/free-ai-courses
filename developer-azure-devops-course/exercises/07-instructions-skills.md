# Exercise 07 · Reproduce reusable context

**Prerequisite:** [lesson 07](../lessons/07-instructions-skills.md). Use only the delivered instruction/skill files.

## Your task

1. Open the course-root instruction file and the three starter `.github` context files named in the lesson.
2. Check `java.instructions.md`'s `applyTo` and compare its intended scope with your open workspace.
3. In a fresh Chat, explicitly attach the starter instructions, Java instructions, and `java-unit-tests/SKILL.md`. For native discovery practice, optionally open `starter/` as a folder in a second VS Code window and use Add Context to attach the root instructor/config/lesson files.
4. Ask for a short test-workflow summary and two scenarios, with no edits or execution.
5. Check references/diagnostics if your installed VS Code supports them. Record **automatic discovery**, **explicit attachment**, or **manual reading** accurately.

**Independent challenge:** propose one concise instruction improvement in an unsaved note and explain its scope. Do not change global or organization settings.

## STOP and evidence

Supply paths, version/support observation, actual context method, and the bounded response.

## Recovery

When native skills are unavailable, read the Markdown workflow manually. No slash-command registration is necessary.

## Completion criteria

- [ ] You distinguish persistent conventions, path scope, and workflow skills.
